# Smart-road-cleaning-rover
A compact smart rover designed to collect and remove waste from road and public areas without disturbing public and public properties. It should be easy maintenance, affordable,durable,and shouldn't interrupt traffic it should be as easy to clean every area and it should be adopted everywhere
